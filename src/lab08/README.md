# Отчет по лабораторной работе №8

## Модель данных `Student`

```python
{
    "fio": "Иванов Иван Иванович",
    "birthdate": "2007-05-14",
    "group": "БИВТ-26-6-1",
    "gpa": 4.3
}
```

Список обязательных
`STUDENT_FIELDS = ("fio", "birthdate", "group", "gpa")`.

### Создание и проверка записи

Функция `make_student(fio, birthdate, group, gpa)` создаёт новую запись,
удаляет лишние пробелы в ФИО и названии группы, приводит средний балл к
`float` и запускает валидацию.

Функция `validate_student(rec)` проверяет:

- передан словарь;
- набор ключей в точности совпадает с `STUDENT_FIELDS`;
- `fio` и `group` являются непустыми строками;
- дата имеет формат `YYYY-MM-DD`, существует и не находится в будущем;
- `gpa` является числом, и находится в диапазоне от `0` до `5`.\

Пример создания записи:

```python
from src.lab08.models import make_student

student = make_student(
    "Иванов Иван Иванович",
    "2007-05-14",
    "БИВТ-26-6-1",
    4.3,
)
print(student)
```

Результат:

```Shell
{'fio': 'Иванов Иван Иванович', 'birthdate': '2007-05-14',
 'group': 'БИВТ-26-6-1', 'gpa': 4.3}
```

## Функции модели

- `make_student(...)` — создаёт и валидирует запись студента;
- `validate_student(rec)` — проверяет структуру и значения готовой записи;
- `student_age(rec, today=None)` — вычисляет полное количество лет;
- `format_student(rec)` — формирует строку с ФИО, группой, возрастом и GPA;
- `student_to_dict(rec)` — возвращает валидированную копию записи;
- `student_from_dict(d)` — десериализует словарь, берёт обязательные поля,
  приводит `gpa` к `float` и валидирует результат;
- `update_student(rec, **fields)` — дополнительная функция, возвращающая
  новую запись с изменёнными полями, не изменяя исходный словарь.

Пример форматирования:

```python
from src.lab08.models import format_student

print(format_student(student))
```

Пример результата:

```text
Иванов И.И. (БИВТ-26-6-1), 18 лет, GPA 4.30
```

Возраст можно вычислить на определённую дату:

```python
from src.lab08.models import student_age

print(student_age(student, "2026-05-13"))
```

Функция `update_student` не меняет исходную запись:

```python
from src.lab08.models import update_student

updated = update_student(student, gpa=4.8)

print(student["gpa"])  # 4.3
print(updated["gpa"])  # 4.8
```

Неизвестное поле вызывает `KeyError`, а неверное новое значение —
`ValueError`.

## Сериализация JSON

### Запись JSON

`students_to_json(students, path)` принимает список или кортеж записей,
валидирует каждую запись и сохраняет массив объектов в JSON. Используются
кодировка UTF-8, `ensure_ascii=False` и отступ в два пробела.

```python
from src.lab08.models import make_student
from src.lab08.serialize import students_to_json

students = [
    make_student("Иванов Иван Иванович", "2007-05-14", "БИВТ-26-6-1", 4.3),
    make_student("Петрова Анна Сергеевна", "2006-11-02", "БИВТ-26-6-1", 4.8),
]

students_to_json(students, r"data\lab08\students_output.json")
```

JSON до преобразования записи в Python:

```json
[
  {
    "fio": "Иванов Иван Иванович",
    "birthdate": "2007-05-14",
    "group": "БИВТ-26-6-1",
    "gpa": 4.3
  }
]
```

JSON после чтения и десериализации снова превращается в список словарей
`Student` с теми же четырьмя полями.

### Чтение JSON

`students_from_json(path)` читает JSON, проверяет, что корневой объект
является списком, а затем пропускает каждую запись через
`student_from_dict`.

```python
from src.lab08.serialize import students_from_json

students = students_from_json(r"data\lab08\students_input.json")
for item in students:
    print(item)
```

Для JSON используется политика `strict`: если хотя бы одна запись
некорректна, загрузка прекращается и возбуждается `ValueError` с номером
записи и причиной ошибки. Битые записи не пропускаются, поскольку это
позволяет не скрывать повреждение входного файла.

Например, для записи с `gpa = 7` будет сообщено:

```text
ValueError: Ошибка при записи №1: Поле 'gpa' должно быть в диапазоне от 0 до 5, получено: 7
```

Отсутствующий файл вызывает `FileNotFoundError`, а JSON, корнем которого
является не список, — `ValueError`.

## Дополнительное чтение CSV

Она ожидает CSV с заголовком:

```text
fio,birthdate,group,gpa
```

`csv.DictReader` читает все значения как строки, поэтому поле `gpa`
отдельно преобразуется в `float` до вызова `student_from_dict`. После этого
запись проходит обычную валидацию модели.

Политика обработки также strict: неверный заголовок, лишний столбец,
нечисловой GPA или другая ошибка строки прекращают чтение и вызывают
`ValueError` с номером строки.
